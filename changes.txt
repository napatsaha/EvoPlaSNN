v1.3.15.0 (2026-08-25)
- SynapseLayer pre- and post-traces
    - Added init args: tau_pre, tau_post, pre_trace, post_trace
    - New settable properties: tau_pre, tau_post
    - New methods: update_traces, get_pre_trace, get_post_trace
    - Added internal trace variables for both pre and post traces:
        _use_pre_trace, _use_post_trace, _pre_trace, _post_trace, _pretrace_tssp, _posttrace_tssp
        _pretrace_last, _posttrace_last
    - Only a 'recent' or last spike only trace is implemented for the sake of simplicity
    - Implemented trace update for both step-wise and event-driven simulation method
- New SynapseLayer method `.update_traces()` which is called during `SNN.forward()`
- Ability for NeuronLayer to turn off traces by specifying `trace_type='none'`
- Inside `BaseLearningRule.prepare_inputs()`
    - SynapseLayer's new `get_pre_trace()` and `get_post_trace()` is now called instead of tiling traces
    - Pre and Post spike use `np.broadcast_to` instead of `tile_array()` to prepare to synapse shape

    - Expand out the for loop SNN.init for normalising neuron_params as list

v1.3.13.0 (2026-08-25)
- `LogRealParam` as an extension of `RealParam`
    - uses `base` to control exponent

        for future uses

    - Only used for extracting values in `EvolvableLearningRule._extract_values_from_genes()`
- Added default Param kwargs for 'learning_rate' and 'tau_syn' in base `EvolvableLearningRule.default_gene_specs`
- `BaseParameter.mutate()` can take a single bool input, which will be applied to all gene positions
    - Removed (int, float) conditions of `flags=`
- Added `dtype` argument to `BaseParameter` which will be set automatically by children's `__init__`, 
    in order to prevent unintentional int dtype to be preserved during mutation (which would lose information in float resampling)
